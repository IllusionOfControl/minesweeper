## Что изменилось по этапам

### Этап 0 — сборка (`stage-0`)
Приведён в порядок `CMakeLists.txt`: единый `find_package(SFML)`, линковка только используемых
компонентов, прямые слеши в путях, убран хардкод `Debug`, требование C++17. Каталоги сборки
добавлены в `.gitignore`.

### Этап 1 — критические баги (`stage-1`)
- **B1**: исправлен fall-through в `switch` обработчика ввода и чтение неверного члена `union`
  (ложные клики при движении мыши у края поля).
- **B2**: инициализированы поля `StateManager` и `GameState` (устранён UB).
- **B5**: безопасный `tryParseInt` вместо «голого» `std::stoi`.
- **Q5**: `AssetManager` бросает понятную ошибку, `main` её перехватывает.

### Этап 2 — игровая логика и тесты (`stage-2`)
- **A1**: вся логика вынесена в SFML-независимый класс `Board`; `GameState` теперь только ввод
  и рендеринг.
- **B3**: рекурсивный flood fill заменён на итеративный.
- **L3**: реализован «аккорд» (средняя кнопка).
- **L1/L4/L5**: починена визуализация победы, полный `reset()`, счётчик мин без искусственного дна.
- **Q2/Q4**: типизированное состояние клетки вместо битовой упаковки, `std::mt19937` вместо `rand()`.
- **L2**: безопасность только первой клетки — оставлено осознанно и задокументировано.
- **Тесты**: подключён Catch2 (`FetchContent`), покрыта логика `Board`.

### Этап 3 — окно и состояния (`stage-3`)
- **B4**: окно создаётся один раз; состояния меняют размер через `resizeWindow()` (без мерцания).
- **A2**: оставлена стековая модель `StateManager` (replace/push/pop), задокументирована, покрыта
  unit-тестами.
- **A3**: `[&]` заменены на `[this]` в колбэках.

### Этап 4 — чистка дубликатов и мёртвого кода (`stage-4`)
- **A4**: общая фабрика `WidgetFactory` (кнопки меню/выхода, фон) и базовый класс
  `PassiveComponent` для статичных виджетов.
- **Q6**: удалены мёртвый код и неиспользуемые поля/текстуры; магические числа заменены на
  именованные константы.

### Этап 5 — константы и нейминг (`stage-5`)
- **Q2/Q3**: `#define` → `constexpr`; пресеты сложности → `constexpr DifficultyData`; удалены
  мёртвые `CELL_*`/`GAME_*`; убран повторный `SQUARE_SIZE`.
- **Q1**: `LoadFont/GetFont` → `loadFont/getFont`, `_data` → `mData`.
- **Q7**: комментарии на английском (русские удалены ранее; проверено по кириллице).

### Этап 6 — инфраструктура (`stage-6`)
- **C2**: рабочая директория переключается на папку exe; ресурсы копируются рядом с бинарником.
- **CI**: GitHub Actions (Windows + vcpkg): сборка и `ctest` на push/PR.
- **README**: исправлен URL, добавлены разделы архитектуры и запуска тестов.

## Что осталось (ручные шаги)

Эти шаги выполняются вне среды агента (нет тулчейна — см. также заметки памяти проекта):

1. **Сборка и тесты** в Developer PowerShell for VS 2026:
   ```powershell
   cmake -B build -DCMAKE_TOOLCHAIN_FILE="<vcpkg>/scripts/buildsystems/vcpkg.cmake"
   cmake --build build
   ctest --test-dir build --output-on-failure
   .\build\Debug\minesweeper.exe
   ```
2. **Ручной прогон** всех режимов (победа/проигрыш/сброс, аккорд, навигация между экранами).
3. **PR** `cleanup → master`.

## Ограничение проверки

Среда агента не содержит cmake/SFML/VS-тулчейна, поэтому код написан и закоммичен, но **не
компилировался и не прогонялся** на стороне агента. Финальная верификация — за разработчиком.
